Privacidad y transparencia

Política de privacidad

Última actualización: 18 de noviembre de 2026

Esta Política de privacidad describe las prácticas de tratamiento de datos de la aplicación móvil de descubrimiento de restaurantes y reservas de mesas, identificada por el nombre de paquete com.dineely.android.app (en adelante, «la Aplicación»).

Resumen de privacidad

Según las prácticas declaradas por el responsable de la Aplicación, la Aplicación no recopila datos personales ni otros datos de los usuarios y no comparte ni transmite datos de los usuarios a terceros.

1. Identificación y contacto

Esta política corresponde a la Aplicación con identificador com.dineely.android.app. Para consultas sobre privacidad o sobre la Aplicación, puedes escribir a support@doradorest.com.

2. Datos que recopilamos

La Aplicación no recopila información personal ni otros datos de los usuarios. No solicita ni conserva nombres, direcciones de correo electrónico, números de teléfono, ubicación, contactos, identificadores publicitarios ni datos de pago con fines de recopilación de datos.

3. Uso y tratamiento de datos

Al no recopilar datos de los usuarios, la Aplicación no utiliza esa información para publicidad, análisis de comportamiento, elaboración de perfiles, seguimiento ni otros fines de tratamiento.

4. Compartición y transmisión de datos

La Aplicación no vende, comparte, divulga ni transmite datos de los usuarios a terceros, socios comerciales o proveedores de servicios.

5. Almacenamiento, conservación y eliminación

La Aplicación no almacena datos personales ni otros datos de los usuarios. Por lo tanto, no mantiene períodos de conservación de dichos datos ni dispone de datos de usuario recopilados que deban eliminarse. Si tienes alguna consulta relacionada con la eliminación de datos, puedes comunicarte con support@doradorest.com.

6. Seguridad de la información

Dado que la Aplicación no recopila, transmite ni almacena datos de los usuarios, no se realizan operaciones de tratamiento de esos datos dentro de las prácticas aquí descritas. Si estas prácticas cambian, actualizaremos esta política para reflejar las medidas aplicables.

7. Privacidad de los menores

La Aplicación no recopila datos personales ni otros datos de usuarios, incluidos menores de edad. Si tienes dudas relacionadas con la privacidad de un menor, contáctanos en support@doradorest.com.

8. Servicios y sitios externos

La Aplicación puede mostrar información sobre restaurantes. Esta política describe únicamente las prácticas de la Aplicación y no las de sitios web o servicios externos que los usuarios puedan visitar por separado. Esos servicios pueden tener sus propias políticas de privacidad.

9. Derechos y solicitudes de privacidad

Puedes enviarnos cualquier consulta, solicitud o inquietud sobre privacidad al correo support@doradorest.com. Como no recopilamos ni conservamos datos de los usuarios, no mantenemos registros de datos de usuario para acceder, rectificar o suprimir.

10. Cambios a esta política

Podemos actualizar esta Política de privacidad si cambian las funcionalidades de la Aplicación, nuestras prácticas de datos o los requisitos legales. Publicaremos la versión vigente en esta misma página e indicaremos la fecha de la última actualización.

11. Contacto

Para cualquier pregunta sobre esta Política de privacidad, escribe a support@doradorest.com.
